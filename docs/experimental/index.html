Experimental builds

Unfinished, automated builds straight off a dev branch. They let you try features before they ship — and help us find bugs. Not for daily use.

These builds are unsigned and unstable. Expect bugs, missing features, and rough edges. They are not code-signed, so your OS will warn you on first launch. Don't trust them with anything important. For a stable build, use the latest release.
Windows preview Dev branch
auto-updated · windows-support

Splice is a macOS app; the Windows port is a work in progress. This build launches with the editor and terminal working. It rebuilds automatically on every change to the windows-support branch.

Known limitations

  • —Unsigned — SmartScreen warns on launch (click More info → Run anyway)
  • —SSH / SFTP remote workspaces are not available yet
  • —Window chrome and keyboard shortcuts are still being adapted to Windows
